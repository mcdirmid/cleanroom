# Guide: Pretense Interface and Fake State Machine Author

## Summary

The artifact is a Pretense interface module (`pretense_intf/<name>_pretense.py`) implementing the behavioral contract of `low/<name>.pyi`, submitted via `submit(...)`. Tool-managed metadata must not be edited manually. The module defines a **stateless** `<Iface>StateMachine(StateMachine[Any])` (zero `self.state` access or mutation), a **stateful** `<Iface>FakeStateMachine(<Iface>StateMachine)` (owning `make_initial_state(self) -> <Iface>State`, `@transition.seeding()`, and `inner_<method>` fake implementations without redeclaring `state:` on the class), `Fake<Iface> = synthesize_fake(<Iface>FakeStateMachine)`, `make_<iface>_fake`, `Fake<Iface>FuzzTest = compile_hypothesis_test_case(<Iface>FakeStateMachine, name="Fake<Iface>FuzzTest")`, and optional `Test<Iface>Fake(unittest.TestCase)` fixed tests only for branches not covered by fuzzing. For multi-protocol parts (`low/<name>.pyi` declaring multiple `@singleton_type` protocols), define one `<Iface>StateMachine`, `<Iface>FakeStateMachine`, `make_<iface>_fake`, and `Fake<Iface>FuzzTest` per protocol.

API signatures from `pretense` and `pretense.compiler`: `StateMachine(state=None, transitions=None, invariants=None, singletons=None)`; `@transition(target_method_or_name, *, name=None)`; `@transition.seeding()`; `@domain(valid=None, invalid=None)` (decorating `(self, val) -> bool` methods on `<Iface>StateMachine` where `valid(self) -> Sequence[T]` and `invalid(self) -> Sequence[object]`); `require(cond: bool, error: type[BaseException] = ContractError)`; `require_arg(arg: Any, domain: Any, error: type[BaseException] = ContractError)`; `require_env(cond: bool, exception_cls: type[Exception])`; `@test_only`; `synthesize_fake(sm_cls: type[StateMachine[Any]]) -> type[Any]`; `compile_hypothesis_test_case(sm_cls: type[StateMachine[Any]], *, sut_factory=None, name: str = ...)`. Transitions model target methods 1:1 on `<Iface>StateMachine`, handling branching, pre-state snapshots via `self.inner_<query>()`, `ret = self.inner_<method>(*args)` delegation to `...` stubs, and single-argument `assert` checks. Environmental/operational guards (`*Exception`) use `require_env(self.inner_<test_only_guard>(), ExpectedException)` over `@test_only` methods contracted in `low/<name>.pyi`. Property contracts use `@transition(name="<prop>")` on a plain method without `@property`.

> META: "Pretense interface modules separate the stateless interface contract (<Iface>StateMachine) from the stateful in-memory fake (<Iface>FakeStateMachine) so independent implementations and cross-tests share one pure specification."

## Verification failure

Interface targets are verified in `bin/check_files` via static checks (`pretense_lint`, `pyright`) and runtime fake verification (`uv run pretense --cov`), exercising `Fake<Iface>FuzzTest` and optional `Test<Iface>Fake`. When verification passes on modified code, conclude via `submit(target="<target_file>", change_summary="...")`. Invoking `fail` or `reject` after modifying code that passes verification is prohibited. If the target is unmodified and feedback is incorrect, invoke `reject(target="<target_file>", reason="<explanation>")`. When Hypothesis fuzzing reports a failing witness value, refine the `@domain` validator or `valid=` sequence rather than blacklisting the witness value.

## Lint checks

- [ ] `<Iface>StateMachine` inherits `StateMachine[Any]` and never accesses or mutates `self.state` (`PRE_LINT_INTF_NO_STATE`)
- [ ] `<Iface>FakeStateMachine` inherits `<Iface>StateMachine`, implements `make_initial_state(self) -> <Iface>State` (without redeclaring `state: <Iface>State` on the class, which conflicts with `StateMachine.state`), owns `@transition.seeding()` methods, and contains zero non-seeding `@transition` (`PRE_LINT_FAKE_NO_OUTER_TRANSITION`) and zero `require`/`require_arg` calls (`PRE_LINT_FAKE_NO_REQUIRE`)
- [ ] Target imports use package-qualified paths (`from <scope>.parts.<unit>.lib.<module> import ...`); `Fake<Iface> = synthesize_fake(<Iface>FakeStateMachine)` and `Fake<Iface>FuzzTest = compile_hypothesis_test_case(<Iface>FakeStateMachine, ...)` are defined (`PRE_LINT_INTERFACE_TRANSITION_COVERAGE`)
- [ ] `<Iface>StateMachine` `inner_<method>` stubs use `...` (ellipsis) with zero `raise` statements (`PRE_LINT_NO_RAISE`), zero `assert`, and zero `self.state` (`PRE_LINT_NO_CALL_TARGET_IN_INTERFACE`)
- [ ] `Domain` (`PRE_LINT_REQUIRE_ARG_NO_DOMAIN`), bare lambdas, fixed sets/collections, and undecorated `def` functions are prohibited in `require_arg` (`PRE_LINT_REQUIRE_ARG_DOMAIN_FORM`)
- [ ] `@domain(valid=..., invalid=...)` decorates methods on `<Iface>StateMachine` (`PRE_LINT_DOMAIN_MUST_BE_METHOD`) without `initial_edges=` (`PRE_LINT_DOMAIN_NO_INITIAL_EDGES`)
- [ ] `require(...)` inspects state/queries only and never references transition input arguments (`PN009`); `require`/`require_arg` must attach `error=<*Error>` for every contracted `*Error` violation (`PRE_LINT_REQUIRE_MUST_BE_ERROR`), including multi-arg `*Error` dataclasses (pretense instantiates them safely); `*Exception` uses `require_env(...)` (`PRE_LINT_REQUIRE_ENV_MUST_BE_EXCEPTION`)
- [ ] Read-only Pretense API stubs are available in `support/lib/pretense.pyi`
- [ ] All assertions use single-argument `assert test` (`PRE_LINT_ASSERT_SINGLE_ARG`); Pyright passes with zero errors

## Stateless interface state machine

- [ ] Declare one `@transition(Iface.method)` per contracted method on `<Iface>StateMachine` (`PN_STRICT_1_TO_1`); for contracted `@property` accessors, use `@transition(name="<prop>")` without `@property`
- [ ] Snapshot pre-state exclusively through contracted query methods or `@test_only` accessors (calling `self.inner_<query>()`) before calling `ret = self.inner_<method>(*args)`. Never invent non-contracted `inner_*` query stubs for preconditions whose state is not exposed by `low/<name>.pyi`; instead invoke `bin/fail` blaming `low/<name>.pyi` to add the needed `@test_only` members.
- [ ] Declare `require_arg(arg, domain)` for every transition parameter (including `Any`/`Optional[Any]`) using concrete runtime types (`int`, `str`, `float`, `bool`, `object`, `Enum`, `Collection[T]`, `Optional[T]`) or `@domain(valid=..., invalid=...)` methods on `<Iface>StateMachine` (use `object` rather than `typing.Any` for unconstrained arguments)
- [ ] In `@domain`, `valid` and `invalid` take `(self)` (no `draw`) and return finite `Sequence` values (deterministic fixed-seed `random.Random` sampling is allowed). `invalid` candidates must be **well-typed but precondition-violating** values (not type-invalid junk such as `0` or `None` when `str` is expected). When a state-derived provider has zero matching items (e.g. no registered ids yet), return `()` rather than a synthetic fallback like `["a"]` (the fuzzer skips transitions whose `valid` provider is empty; ghost fallbacks corrupt precondition gates). Prefer typed module-level helper functions `def _provider(sm: <Iface>StateMachine) -> Sequence[...]` over `lambda self:` so Pyright infers `sm` cleanly; `@transition` bodies must never use `lambda` (`PN002_NO_LAMBDAS`).
- [ ] Gate operational `*Exception` conditions via `require_env(self.inner_<test_only_guard>(), ExpectedException)` using `@test_only` methods from `low/<name>.pyi`
- [ ] Transition methods, `@domain` validators, and `Test<Iface>Fake` methods use brief plain-prose docstrings or comments describing modeled behavior and never cite specification contract slugs (`[slug:...]` or `<unit>.<contract>.<facet>`)

## Stateful fake state machine and fuzzing

- [ ] Define `@dataclass class <Iface>State` and `make_initial_state(self) -> <Iface>State` on `<Iface>FakeStateMachine`
- [ ] Implement every `inner_<method>` (and `inner_<test_only_guard>`) on `<Iface>FakeStateMachine` by reading/mutating `self.state` and returning fake values without calling `sut(...)` or raising `*Error`
- [ ] Define `@transition.seeding()` methods exclusively on `<Iface>FakeStateMachine` to seed fake state for fuzzing
- [ ] Provide `make_<iface>_fake()` and `Fake<Iface>FuzzTest`; `make_*_fake` factory functions and `Test*Fake` classes are exempt from `pretense_intf` line-coverage enforcement, so use `Test<Iface>Fake(unittest.TestCase)` only for valid-transition branches not reached by fuzzing (never to exercise `make_*_fake` factories; contract error tests belong in `Test<Impl>Real` via `.violating(...)`)
