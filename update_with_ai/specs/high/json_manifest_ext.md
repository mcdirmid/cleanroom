# json_manifest_ext external component

## Purpose

The json_manifest_ext external component specifies the external JSON build target manifest schema generated by the build system.

Target execution requires reading build metadata emitted by the build system. The json_manifest_ext external component encapsulates external JSON field formats distinguishing target node identifier strings, relative filesystem path strings, prompt instructions, and verification commands.

**Out of scope:** The json_manifest_ext external component does not resolve package directories, construct dependency graphs, or configure sandboxes; these are handled by other components.

## Grounding Gaps Covered

The json_manifest_ext component provides the external domain knowledge and serialization schema required to parse target manifest files emitted by the build system:

- Build manifest JSON schema: Defines the structured JSON object schema emitted by build system rules, including field mappings for target labels, direct dependencies, silent dependencies, star dependencies, feedback dependencies, optional guide targets, optional configuration targets, declared primary source files, template file paths, silent source files, task prompt strings, and verification command strings.

- JSON text deserialization: Decodes raw UTF-8 JSON text documents into structured in-memory records, validates required manifest fields, provides default collections for omitted dependency lists, and handles JSON parsing errors and structural malformations.

- Target and path string extraction: Extracts raw Bazel target coordinate strings and package-relative source file path strings from manifest fields for consumption by graph storage and loader services.
