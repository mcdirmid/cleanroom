# json_manifest_ext

## Purpose

Specifies the external JSON build target manifest schema generated by the build system.

Target execution requires reading build metadata emitted by the build system. The JSON manifest schema defines external field formats distinguishing target node identifier strings, relative filesystem path strings, prompt instructions, and verification commands.

## Types

- A *json manifest* is an external JSON record written by the build system describing a target's configuration, sources, and dependencies
- A *manifest node reference* is an external target identifier string representing a workspace target (such as a target label, dependency target, guide target, feedback target, or config target)
- A *manifest file path* is an external filesystem path string relative to a target package directory (such as a declared source file, template, or silent source file)

## Behavior

- A *json manifest* defines *manifest node references* for target label, direct dependencies, silent dependencies, star dependencies, feedback dependencies, guide target, and config target.
- A *json manifest* defines *manifest file paths* for declared source file, template, and silent source files.
- A *json manifest* provides an optional task prompt string and optional verification command string.
- A *json manifest* deserializes JSON format text into *manifest node references*, *manifest file paths*, task prompt, and verification fields.
