# Agent Part (`update_with_ai/parts/agent`)

## Purpose

The **agent** part establishes the foundational session abstractions, operational policies, virtualized file addressing, and target-level execution configurations governing autonomous AI agent interactions in Cleanroom.

Rather than exposing physical host paths and ambient machine environments directly to language model agents—which causes hallucinated paths, cross-environment drift, and context pollution—the agent part creates a secure, virtualized execution boundary. It defines the lifecycle scope for individual agent sessions, restricts file interactions through virtual file aliases with explicit read/write permission tiers, parses and extracts model configuration parameters, and models task prompts and node definitions for dependency-directed workflows.

## Key Components & Specifications

According to the high-level specifications in [`update_with_ai/parts/agent/high/`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high):

- [`session.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/session.md): Defines the canonical lifecycle tier identifying agent session boundaries beneath the system-wide application environment. It ensures that ephemeral conversation state, session configurations, and tool allocations do not leak across distinct agent runs.
- [`agent_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/agent_config.md): Formalizes system-level operational policies and execution limits for agent sessions, including conversation turn limits, trailing character limits for superseded arguments (`supersede arg keep`), follow-up tool call injection, progressive guide delivery (`step mode`), startup file inspection, and delta-based edit reporting.
- [`file_alias.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/file_alias.md): Decouples agent session file operations from physical filesystem paths. It provides the `FileAlias` abstraction distinguishing *bound files* (mapped to workspace files with an owning node, categorized as *read-only* or *read-write*) from *unbound files*. It provides the `AliasManager` which resolves relative string paths to file aliases and sanitizes agent-visible text by masking host filesystem paths.
- [`node_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_config.md): Unifies node-level execution configurations for an active session. It models `RoleConfig` (the active role, sequence of nodes being cleaned, and execution version counter) and `SessionConfig` (resolved read-only and read-write files, step-by-step guides, starter templates and template parameters, verification checks, blame targets, and incoming defect feedback).
- [`node_storage.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_storage.md): Extends DAG storage with target manifest metadata. It preserves target definitions, task prompts, and dependency relationships, and evaluates node dirtiness dynamically by comparing in-band source file metadata against dependency change timestamps.

## How It Is Used by Other Parts

The `agent` part is a central domain contract consumed across the entire Cleanroom ecosystem:

- **`control`**: Uses [`node_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_config.md), [`file_alias.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/file_alias.md), and [`node_storage.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_storage.md) to set active session roles, discover ready dirty tasks, synthesize task prompts with user-facing aliases, evaluate verification checks, and attribute defects back to culprit upstream nodes.
- **`sandbox`**: Relies on [`file_alias.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/file_alias.md) and [`node_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_config.md) to enforce read-only vs. read-write permissions during file reads and edits, deliver progressive guides, evaluate verification checks in `check_files`, and validate blame targets during `submit`, `fail`, or `blame`.
- **`workspace`**: Uses [`file_alias.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/file_alias.md) and [`node_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_config.md) to map declared bound files, scaffold initial project trees, populate starter templates, and synchronize files between isolated role workspaces and the canonical workspace.
- **`subagent`**: Uses [`session.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/session.md), [`node_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_config.md), and [`node_storage.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_storage.md) to configure session scopes and task instructions when dispatching roles to autonomous subagents.
- **`antigravity` & `dsh`**: Use [`session.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/session.md) and session config types to bind execution turns to isolated role environments in Google Antigravity and DeepSeek Harness.
- **`loop` & `openai`**: Use [`session.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/session.md), [`agent_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/agent_config.md), and [`node_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_config.md) to enforce conversational turn limits, assemble prompt messages, and manage driver execution.
- **`workspace_cli`**: Uses [`node_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_config.md) and [`file_alias.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/file_alias.md) to implement workspace CLI commands (`get-work`, `check-files`, `submit`, `blame`).
- **`uv`**: Implements [`node_config.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_config.md) from Python build targets and manifest definitions.
- **`metadata`**: Implements [`node_storage.md`](file:///Users/seanmcdirmid/projects/cleanroom/update_with_ai/parts/agent/high/node_storage.md) through source file in-band comment metadata.
